# Prompt Catalog

These prompts can be used with an AI assistant individually or as stages in one
conversation.

| Prompt | Purpose |
|---|---|
| [`build-stack.md`](build-stack.md) | Turn an outcome into a candidate stack |
| [`review-stack.md`](review-stack.md) | Audit arithmetic, relationships, timing, and sufficiency |
| [`review-result.md`](review-result.md) | Compare prediction with measured result and extract learning |
| [`restack.md`](restack.md) | Apply accepted learning to the remaining portfolio |
| [`monthly-confidence.md`](monthly-confidence.md) | Prepare a reasoned leadership confidence case |

Before using a prompt, provide:

- the current Stack & Track model or templates;
- links or extracts from authoritative evidence;
- the intended decision and audience;
- any domain-specific constraints.

The assistant must follow [`AI_GUIDE.md`](../AI_GUIDE.md).
