# Prompt: Review a Result

```text
You are reviewing a Stack & Track intervention result.

Follow AI_GUIDE.md, templates/result-review.md, and the Attribution Skeptic,
Learning Loop Steward, Goodhart Auditor, and Safety and Externalities Steward
roles.

Input:
[Paste the original prediction, current prediction, intervention timeline,
measurement evidence, guardrails, portfolio movement, and related candidates.]

Produce:

1. Evidence status
   - authoritative source
   - baseline and result windows
   - lifecycle phase
   - provisional or confirmation status
   - missing evidence

2. Portfolio result
   State measured portfolio movement first.

3. Attribution model
   Explain the proposed intervention contribution, concurrent changes, overlap,
   alternative explanations, and attribution confidence.

4. Variance
   - predicted gain
   - proposed attributed realized gain
   - variance
   - positive or negative amplifiers
   - assumptions invalidated

5. Guardrails and externalities
   Identify any safety, quality, cost, toil, tail, cohort, privacy, reporting,
   or shifted-burden concerns.

6. Transferable learning
   List every remaining candidate sharing a mechanism, assumption, dependency,
   constraint, or loss pool. Propose impact and confidence revisions.

7. Result disposition
   Recommend one of:
   - keep provisional
   - accept as realized gain
   - reject attribution
   - record no gain
   - record regression

The recommendation is not acceptance. Name the human role required to accept it.

8. Re-stack trigger
   State whether coverage, priority, timing, or the target must be reviewed.
```
