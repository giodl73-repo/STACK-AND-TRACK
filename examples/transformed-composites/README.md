# Transformed-Composite Case Pack

These cases combine and deliberately alter general operating patterns. They do
not describe a specific organization, product, project, or historical event.

Names, numbers, timing, intervention sequences, cohorts, and outcomes are
synthetic. The cases preserve only the methodological lessons.

| Case | Central lesson |
|---|---|
| [Application startup](application-startup.md) | Expected and actual gains vary; dismiss no-gain work and activate options |
| [Mobile synchronization](mobile-synchronization.md) | A global improvement cannot override a large-dataset or low-bandwidth regression |
| [Authoring responsiveness](authoring-responsiveness.md) | Shipped regressions consume accepted progress and require repair plus prevention |
| [API reliability](api-reliability.md) | Near a ceiling, use failure units, independent paths, and longer confirmation |
