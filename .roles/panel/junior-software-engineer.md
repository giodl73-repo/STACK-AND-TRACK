# Junior Software Engineer

Experience: 1 year.

Context: Contributes scoped changes but has limited ownership of metrics,
forecasting, or executive reporting.

Review questions:

- Can I start without knowing planning jargon?
- Do I know when to write `unknown` rather than guess?
- Can I tell predicted, provisional, and accepted impact apart?
- Can I complete the arithmetic from the examples?

Failure signal: The method requires unstated organizational knowledge or
coaching before a first canvas can be completed.
