# STACK-AND-TRACK Context

## Mission

Help teams build plans that credibly add up to an outcome, learn from actual
results, and continuously redirect effort toward the highest remaining impact.

## Core loop

1. Define the baseline, target, unit, horizon, and measurement source.
2. Stack candidate interventions with predicted impact and confidence.
3. Remove overlap and expose dependencies.
4. Pareto-prioritize the smallest credible portfolio that can reach the target.
5. Prefer meaningful surplus coverage when feasible; 2x is a useful aspiration,
   not a universal physical requirement.
6. Track predicted and realized gains in the same unit.
7. Explain positive and negative variance.
8. Apply the learning to every remaining item.
9. Re-stack until the outcome is reached or the target is explicitly revised.

## Non-negotiable principles

- A plan must add up before work begins.
- Activity is not impact.
- Realized gain outranks promised gain.
- Confidence, overlap, dependencies, and diminishing returns are explicit.
- Priorities change when evidence changes.
- Misses are learning inputs, not facts to hide.
- Bounded metrics require redundant paths, not impossible arithmetic.
- The method must work without custom software.

## Current scope

The repository defines the methodology, examples, templates, AI guidance, and
governance. It contains no substantive implementation code.
